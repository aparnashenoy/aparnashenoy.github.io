aparnashenoy.github.io

Source for my portfolio site, live at https://aparnashenoy.github.io.

A single static page. No build step, no dependencies, no framework — index.html holds the markup, styles and content together. Type is loaded from Google Fonts; everything else is local.

Running it locally

Open index.html in a browser. That's the whole workflow.

Deploying

GitHub Pages serves the main branch root automatically for a repository named <username>.github.io. Pushing to main publishes; there is no other step.
